# Purpose
Подготовить **структуру и черновик** технической статьи под площадку Habr/VC: заголовки, логика, тон, безопасные примеры кода.

# When to use
- Пользователь просит набросок статьи, оглавление или ревью тона.

# Inputs needed
- Тема, целевая аудитория, длина, язык (RU/EN).
- Что можно показать из внутренних систем (без NDA).

# Procedure
1) Сформулировать **тезис** и **ценность для читателя**.
2) Построить **оглавление** (5–9 разделов).
3) Написать **введение** и **заключение** (кратко).
4) Для ключевых разделов — **черновые абзацы** или плейсхолдеры с пометкой «DATA».
5) Добавить **callouts**: «внимание — упрощено», «не для продакшена».

# Output format
1) **Working title** + 2 варианта альтернатив
2) **Outline** (markdown headings)
3) **Draft** (введение + 1–2 ключевых раздела полностью, остальные тезисы)
4) **Disclaimers** (что вымышлено / обезличено)

# Quality bar (self-check)
- [ ] Нет утечки внутренних имён клиентов/серверов.
- [ ] Код-образцы минимальны и компилируемы/правдоподобны.
- [ ] Тон нейтрально-профессиональный без токсичности к вендорам/людям.

# Anti-patterns
- ❌ Копипаста закрытого кода компании.
- ❌ «Волшебные» цифры производительности без методики измерения.
